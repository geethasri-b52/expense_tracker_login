# Expense Tracker with Individual Accounts

Responsive HTML, CSS, and vanilla JavaScript expense tracker using browser localStorage.

## Features
- Create an account with a unique username and password.
- Login and logout.
- Each account sees and manages only its own expenses in that browser.
- Add, edit, delete, search, and filter expense records.
- Spending summary and category breakdown.
- Responsive desktop, tablet, and mobile layout.

## Run in VS Code
1. Extract the ZIP file.
2. Open the `expense_tracker_login` folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Important
This is a frontend-only demonstration. Usernames, passwords, and expenses are stored in localStorage on the current browser/device. This is not secure authentication, and accounts do not sync between browsers/devices. Do not use real or sensitive passwords. Clearing browser storage can remove the saved data.
